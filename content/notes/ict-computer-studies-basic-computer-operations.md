:::callout{type=definition}
**Booting** is the process of starting a computer: when it is switched on, it checks its hardware and loads the operating system from storage into memory, so that it is ready for use.
:::

Using a computer well starts with the basics: switching it on and off correctly, finding your way around the desktop, using the mouse and keyboard, and opening, arranging and closing programs. This lesson explains the **booting process**, the **difference between cold booting and warm booting**, the **parts of the desktop**, mouse and window operations, useful **keyboard shortcuts**, how to **shut down a computer properly**, and how to protect a computer from power problems.

## Learning objectives

By the end of this lesson you should be able to:

- describe the steps in booting a computer
- distinguish cold booting from warm booting
- name and describe the parts of the desktop
- carry out mouse operations and window operations
- use common keyboard shortcuts
- shut down a computer correctly and explain why it matters

## Starting the computer: booting

![The booting process in five steps: 1, power on: the CPU starts the BIOS or UEFI firmware stored in ROM; 2, the power-on self-test (POST) checks memory, keyboard and disks and beeps if there is a fault; 3, the BIOS looks for the operating system on the SSD, hard disk or USB drive; 4, the boot loader copies the operating system's kernel into RAM; 5, the operating system shows the log-in screen, then the desktop](https://wasscetutor.com/img/ict/booting-process.svg)

*Figure 1. The five steps of the booting process. WASSCE Tutor diagram.*

:::callout{type=definition}
**Power-on self-test (POST):** a set of checks the BIOS runs when a computer is switched on, to make sure the memory, keyboard, disks and other key hardware are working.

**BIOS (basic input/output system):** firmware stored in ROM or flash memory on the motherboard that starts the computer, runs the POST and loads the operating system; newer computers use UEFI, which does the same job.
:::

To start a desktop computer safely: switch on the power at the wall socket (and the stabiliser or UPS), then press the power button on the **system unit**, then on the **monitor**. Wait for the log-in screen and type your **password**.

### Cold booting and warm booting

:::callout{type=definition}
**Cold booting:** starting a computer from the off state by switching on the power.

**Warm booting:** restarting a computer that is already on, without switching off the power, such as by choosing Restart or pressing Ctrl + Alt + Delete.
:::

| Cold booting (hard boot) | Warm booting (soft boot) |
|---|---|
| starts the computer from **off** | restarts a computer that is **already on** |
| by pressing the **power button** | by choosing **Restart**, or **Ctrl + Alt + Delete** |
| runs the full POST | may skip some checks, so it is quicker |
| used at the start of the day | used after installing software or when a program **hangs** |

## The desktop

![Parts of the desktop: desktop icons such as This PC, Recycle Bin and Documents on the wallpaper (background); an open window with a title bar and minimise, maximise and close buttons; a mouse pointer; and the taskbar along the bottom with the Start button at the left, buttons for open programs and the notification area and clock at the right](https://wasscetutor.com/img/ict/desktop-elements.svg)

*Figure 2. The parts of a computer desktop. WASSCE Tutor diagram.*

:::callout{type=definition}
**Desktop:** the main screen shown after logging in, on which icons, windows and the taskbar appear.

**Icon:** a small picture that stands for a program, file, folder or command; double-clicking it opens it.

**Taskbar:** the bar, usually along the bottom of the screen, that holds the Start button, buttons for open and pinned programs, and the notification area with the clock.

**Recycle Bin:** a folder that keeps deleted files so they can be restored, until it is emptied.
:::

- **Start button:** opens the Start menu, from which you open programs, settings and the power options.
- **Wallpaper (background):** the picture behind the icons.
- **Notification area (system tray):** shows the clock, volume, network, battery and messages.

## Using the mouse

| Action | How | What it does |
|---|---|---|
| **Point** | move the mouse | moves the pointer onto an item |
| **Click (left-click)** | press and release the left button once | selects an item or presses a button |
| **Double-click** | click the left button twice quickly | opens a file, folder or program |
| **Right-click** | press the right button | shows a **shortcut (context) menu** of options |
| **Drag and drop** | hold the left button down, move, release | moves or copies an item |
| **Scroll** | roll the wheel | moves up or down a page |

## Working with windows

:::callout{type=definition}
**Window:** a rectangular area of the screen in which a program or folder is shown; many windows can be open at once.
:::

- **Minimise (–):** hides the window as a button on the taskbar; the program keeps running.
- **Maximise (□):** makes the window fill the screen; **Restore** returns it to its earlier size.
- **Close (×):** closes the window and the program.
- **Move:** drag the **title bar**. **Resize:** drag an edge or corner.
- **Switch between windows:** click its taskbar button, or press **Alt + Tab**.

## Shutting down correctly

Click **Start → Power → Shut down**, wait until the screen goes dark, then switch off the monitor and the power at the socket.

**Why not just pull the plug?** Switching off without shutting down can **lose unsaved work**, **damage (corrupt) open files** and the operating system, and over time harm the hard disk.

| Power option | What it does |
|---|---|
| **Shut down** | closes all programs and turns the computer off |
| **Restart** | shuts down and starts again (a warm boot) |
| **Sleep** | keeps your work in RAM using a little power; wakes up quickly |
| **Hibernate** | saves your work to the disk and turns off; restores it at the next start |
| **Sign out (log off)** | closes your programs so another user can sign in |
| **Lock** | hides your screen until you type your password again |

## Protecting a computer from power problems

:::callout{type=definition}
**UPS (uninterruptible power supply):** a device with a battery that keeps a computer running for a short time when the mains power fails, giving time to save work and shut down properly.

**Stabiliser (voltage regulator):** a device that keeps the voltage supplied to a computer steady, protecting it from power surges and drops.
:::

:::callout{type=local-example}
**Power cuts and surges.** Where the electricity supply goes off without warning or comes back with a surge, a computer room should use a **UPS** for each computer and a **stabiliser** or **surge protector**. Save your work often (**Ctrl + S**) so a sudden cut loses as little as possible.
:::

:::callout{type=common-mistake}
**Thinking Minimise closes a program.** A minimised program is still **running** and using memory; only **Close** (×) ends it.
:::

## Practice

:::reveal{title="1. Define booting and list the main steps."}
**Booting** is starting a computer and loading the operating system into memory. Steps: **power on** (BIOS starts) → **POST** checks the hardware → the BIOS **finds the boot device** → the **operating system is loaded** into RAM → the **log-in screen / desktop** appears.
:::

:::reveal{title="2. Distinguish between cold booting and warm booting."}
**Cold booting** starts a computer from **off** by pressing the power button. **Warm booting** **restarts** a computer that is already on, using Restart or Ctrl + Alt + Delete, without switching off the power.
:::

:::reveal{title="3. State the use of: (a) double-click, (b) right-click, (c) drag and drop."}
(a) **Opens** a file, folder or program. (b) Shows a **shortcut (context) menu**. (c) **Moves or copies** an item to another place.
:::

:::reveal{title="4. Give the keyboard shortcuts for copy, paste, undo and save."}
Copy **Ctrl + C**, paste **Ctrl + V**, undo **Ctrl + Z**, save **Ctrl + S**.
:::

:::reveal{title="5. Give two reasons why a computer should be shut down properly."}
Any two: to avoid **losing unsaved work**; to avoid **corrupting files** and the operating system; to protect the **hard disk**; to let programs close and save their settings.
:::

## Key points

- **Booting**: power on → POST → find boot device → load OS → desktop. **Cold boot** from off; **warm boot** = restart.
- Desktop: **icons, wallpaper, windows, taskbar, Start button, notification area, Recycle Bin**.
- Mouse: **point, click, double-click, right-click, drag and drop, scroll**.
- Windows: **minimise, maximise/restore, close, move, resize**; switch with **Alt + Tab**.
- Shortcuts: **Ctrl + C, X, V, Z, S, P, A**.
- Always **shut down** properly; use a **UPS** and **stabiliser** against power cuts and surges.
