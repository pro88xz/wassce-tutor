:::callout{type=definition}
**File management** is the organising and handling of files and folders on a computer's storage: creating, naming, saving, copying, moving, renaming, deleting and finding them so that work is easy to find and safe from loss.
:::

A flash drive full of files called "New Document (7)" is hard to use; a drive with clearly named folders for each subject is easy. This lesson explains the **difference between a file and a folder**, how files and folders are arranged in a tree, file names and **file extensions**, and how to create, save, copy, move, rename, delete, find, compress and back up files.

## Learning objectives

By the end of this lesson you should be able to:

- define a file, a folder, a subfolder, the root directory and a path
- read and write the path to a file
- name common file extensions and the type of file each shows
- describe how to create, save, rename, copy, move and delete files and folders
- distinguish between Save and Save As, and between copying and moving
- explain how to find, compress and back up files

## Files and folders

:::callout{type=definition}
**File:** a named collection of related data stored as one unit on a storage device, such as a document, a picture, a song or a program.

**Folder (directory):** a named container used to group related files and other folders.

**Subfolder (subdirectory):** a folder inside another folder.

**Root directory:** the top-level folder of a drive, such as C:\, which holds all the other folders on that drive.

**Path:** the full address of a file or folder, listing the drive and each folder down to it, such as C:\Users\Aminata\Documents\ICT notes.docx.
:::

| File | Folder |
|---|---|
| holds **data** (text, a picture, a song, a program) | holds **files and other folders** |
| has a **name and an extension**, such as report.docx | has a name only |
| opens in a program | opens in the file manager |
| has a size from its contents | its size is the total of what it holds |

Files and folders are arranged like an upside-down **tree**: the drive is the root, folders are branches, and files are the leaves. This is called a **hierarchical (tree) file structure**.

The program used to manage files is the **file manager**: **File Explorer** in Windows, **Finder** on a Mac, and the **Files** app on a phone.

## File names and extensions

A file name has two parts: the **name** and the **extension**, joined by a full stop: **budget.xlsx**.

:::callout{type=definition}
**File extension:** the letters after the last full stop in a file name, such as .docx or .jpg, which show the type of file and the program that opens it.
:::

| Extension | Type of file | Usually opened with |
|---|---|---|
| **.docx** (.doc) | word-processed document | Microsoft Word |
| **.xlsx** (.xls) | spreadsheet | Microsoft Excel |
| **.pptx** (.ppt) | presentation | Microsoft PowerPoint |
| **.accdb** (.mdb) | database | Microsoft Access |
| **.pdf** | document for reading and printing | a PDF reader or browser |
| **.txt** | plain text | Notepad |
| **.jpg**, **.png**, **.gif**, **.bmp** | picture | a photo viewer |
| **.mp3**, **.wav** | sound | a media player |
| **.mp4**, **.avi** | video | a media player |
| **.exe** | program (executable) | runs by itself in Windows |
| **.zip** | compressed folder | the file manager |
| **.html** | web page | a web browser |

**Rules for naming files in Windows:** a name may not contain the characters **\ / : * ? " < > |**; two files in the same folder cannot have the same name; choose names that describe the contents, such as **SSS3 ICT notes term 1.docx**.

## Working with files and folders

**To create a folder:** open the place where you want it, **right-click** an empty space, choose **New → Folder**, type a name and press **Enter**.

**To rename:** right-click the file or folder, choose **Rename** (or press **F2**), type the new name and press **Enter**.

**To delete:** select it and press **Delete**. It goes to the **Recycle Bin**, from which it can be **restored** until the bin is emptied. **Shift + Delete** deletes it permanently.

### Save and Save As

:::callout{type=definition}
**Save:** stores the changes to a file under its current name and in its current place; the first time, it asks for a name and a place.

**Save As:** stores a copy of a file with a new name, in a new place or in a new format, leaving the original unchanged.
:::

### Copying and moving

| Copy (Ctrl + C, then Ctrl + V) | Move (Ctrl + X, then Ctrl + V) |
|---|---|
| the file stays in the **old** place **and** appears in the new place | the file **leaves** the old place and appears in the new place |
| you end up with **two** copies | you still have **one** file |
| used to make a backup or to share | used to reorganise files |

You can also **drag and drop**: dragging to another folder on the same drive **moves** the file; dragging to another drive (such as a flash drive) **copies** it.

### Finding files

Type part of the name in the **search box** of the file manager. You can **sort** files by name, date, type or size, and change the **view** (icons, list, details). The **details view** shows each file's size, type and date modified. Right-click → **Properties** shows a file's size, location, dates and attributes such as **read-only** and **hidden**.

## Compressing and backing up files

:::callout{type=definition}
**File compression:** making a file or folder smaller so that it uses less storage space and is quicker to send; compressed files are often stored as .zip files.

**Backup:** a copy of files kept in a separate place, such as a flash drive, an external disk or cloud storage, so that the files can be restored if the originals are lost or damaged.
:::

To compress in Windows: right-click the files → **Send to → Compressed (zipped) folder**. To open: right-click the .zip file → **Extract All**.

:::callout{type=local-example}
**Organising your school work.** Make one folder called **School**, a subfolder for each class (SSS1, SSS2, SSS3) and, inside each, a folder for every subject. Name files clearly, such as **Biology practical 3 - osmosis.docx**, and back up the School folder to a flash drive or Google Drive every week, in case your computer is stolen or gets a virus.
:::

:::callout{type=common-mistake}
**Thinking a deleted file is gone at once.** A file deleted with the Delete key goes to the **Recycle Bin** and can be **restored**. It is gone only when the bin is emptied, or if it was deleted with Shift + Delete or from a flash drive.
:::

A **file** is a named collection of data, such as a document or a picture. A **folder** is a container that holds files and other folders.
:::

**.xlsx**: spreadsheet; **.pptx**: presentation; **.jpg**: picture (photograph); **.exe**: program (executable file).
:::

:::reveal{title="4. What is the difference between Save and Save As?"}
**Save** stores changes under the **same name and place**. **Save As** stores the file under a **new name, place or format**, keeping the original unchanged.
:::

:::reveal{title="5. Write the steps to create a new folder on the desktop."}
1. **Right-click** an empty part of the desktop. 2. Choose **New**, then **Folder**. 3. **Type** a name for the folder. 4. Press **Enter**.
:::

## Key points

- A **file** holds data; a **folder (directory)** holds files and folders; a **subfolder** is a folder inside a folder.
- Files are stored in a **tree** from the **root directory**; a **path** gives a file's full address, such as C:\Users\Aminata\Documents\notes.docx.
- A file name = **name + extension**; the extension shows the **type of file** (.docx, .xlsx, .pptx, .pdf, .jpg, .mp3, .exe, .zip).
- Operations: **create, open, save, Save As, rename, copy, move, delete, restore, search**.
- **Copy** leaves the original; **move** takes it away. Deleted files go to the **Recycle Bin**.
- **Compress** files to save space; **back up** important files regularly.

:::
