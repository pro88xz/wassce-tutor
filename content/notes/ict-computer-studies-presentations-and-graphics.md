:::callout{type=definition}
**Presentation software** is an application used to create a set of **slides**, combining text, pictures, charts, sound and video, to be shown one after another to an audience as a **slide show**. Microsoft PowerPoint, Google Slides and LibreOffice Impress are examples. **Graphics software** is used to create and edit pictures and drawings.
:::

A good slide show helps a speaker explain clearly; a well-made poster or logo catches the eye. This lesson explains **presentation software**, its features (slides, layouts, themes, **transitions and animations**, speaker notes and views), how to build and deliver a good presentation, and **graphics software**: painting and drawing programs, the **difference between bitmap and vector graphics**, and common image file formats.

## Learning objectives

By the end of this lesson you should be able to:

- define presentation software, name examples and state its uses
- explain slide, placeholder, layout, theme, slide master, transition, animation and speaker notes
- name the views of a presentation program and the use of each
- describe the steps in creating and running a presentation, and the rules of good slide design
- name types of graphics software with examples
- distinguish bitmap (raster) graphics from vector graphics

:::callout{type=definition}
**Slide:** a single page of a presentation, shown full-screen during a slide show.

**Placeholder:** a box with a dotted border on a slide that holds a title, text, a picture or a chart; you click it to add content.

**Slide layout:** the arrangement of placeholders on a slide, such as Title Slide, Title and Content, or Two Content.

**Theme (design template):** a ready-made set of colours, fonts and backgrounds applied to all the slides so they look alike.

**Slide master:** the main slide that stores the design and layout used by every slide, so a change to it changes them all.

**Transition:** the visual effect seen as one slide changes to the next, such as fade, push or wipe.

**Animation:** a movement effect given to an object on a slide, such as text flying in or a picture fading out.

**Speaker notes:** notes typed in the notes pane to help the presenter; they are not shown to the audience.
:::

### Views of a presentation

| View | Use |
|---|---|
| **Normal view** | the main view for creating and editing slides |
| **Slide Sorter view** | shows small copies of all the slides, to rearrange, copy or delete them |
| **Notes Page view** | shows each slide with its speaker notes, for printing |
| **Reading view** | plays the presentation inside the window |
| **Slide Show view** | shows the slides full-screen to the audience |

### Creating and running a presentation

1. Open the program and choose a **blank presentation** or a **template**.
2. Choose a **theme** from the Design tab.
3. Type the **title slide**, then add slides (**New Slide**) with suitable **layouts**.
4. Add **text, pictures, charts, tables, sound, video** and **hyperlinks** from the Insert tab.
5. Add **transitions** between slides and **animations** to objects.
6. Type **speaker notes**, check spelling, and **save** the file (a .pptx file).
7. Run the slide show: press **F5** to start from the first slide, or **Shift + F5** from the current slide. Move on with a click, the **arrow keys** or the **space bar**; press **Esc** to end.

**Printing:** a presentation can be printed as full slides, as **handouts** (several slides on a page, for the audience), as notes pages or as an outline.

### Rules for good slides

- Keep text short: about **six bullet points of six words** each at most (the 6 × 6 rule).
- Use a large font: **24 points or more** for text, bigger for titles.
- Use **strong contrast**: dark text on a light background, or light on dark.
- Use the same theme throughout; use transitions and animations **sparingly**.
- Use **pictures and charts** to explain, not to decorate.
- **Check spelling**, and practise the talk with the slides.

:::callout{type=common-mistake}
**Mixing up transitions and animations.** A **transition** happens **between slides**; an **animation** moves an **object on a slide**, such as a line of text or a picture.
:::

## Graphics software

:::callout{type=definition}
**Graphics software:** an application used to create, edit and arrange images, such as drawings, photographs, logos, diagrams and posters.

**Desktop publishing (DTP):** the use of a computer program to design and lay out pages that combine text and pictures, such as newsletters, posters, cards and magazines.
:::

| Type | Use | Examples |
|---|---|---|
| **Painting (bitmap) programs** | painting and editing pixel images | Microsoft Paint, Adobe Photoshop, GIMP |
| **Drawing (vector) programs** | logos, diagrams, illustrations | CorelDRAW, Adobe Illustrator, Inkscape |
| **Photo-editing programs** | improving and retouching photographs | Photoshop, Lightroom, Snapseed (phone) |
| **Desktop publishing** | posters, newsletters, cards, magazines | Microsoft Publisher, Adobe InDesign, Canva |
| **Computer-aided design (CAD)** | accurate technical drawings and plans | AutoCAD, SketchUp |
| **Animation and 3D** | moving pictures and 3D models | Blender, Adobe Animate |

**Common tools:** select, crop, resize, rotate and flip, brush and pencil, eraser, fill (paint bucket), shapes, text, colour picker, **layers**, and filters to change brightness, contrast or colour.

### Bitmap and vector graphics

![The same circle enlarged two ways: a bitmap (raster) image is made of pixels, so when it is enlarged the square pixels show and the edge looks jagged; it suits photographs in formats such as .jpg, .png and .bmp. A vector image is made of shapes described by mathematics, with points that define the curve, so when it is enlarged the edge stays smooth; it suits logos and drawings in formats such as .svg and .ai](https://wasscetutor.com/img/ict/bitmap-vs-vector.svg)

*Figure 2. A bitmap and a vector image of the same circle, enlarged. WASSCE Tutor diagram.*

:::callout{type=definition}
**Bitmap (raster) graphic:** an image made of a grid of tiny coloured dots called pixels; it loses quality and looks jagged when it is enlarged.

**Vector graphic:** an image stored as shapes (lines, curves and fills) described by mathematical formulas; it can be enlarged to any size without losing quality.
:::

| Bitmap (raster) | Vector |
|---|---|
| made of **pixels** | made of **shapes** described by maths |
| becomes **jagged (pixelated)** when enlarged | stays **sharp** at any size |
| large files for big, detailed images | usually **smaller** files |
| best for **photographs** and detailed paintings | best for **logos, diagrams, maps and text** |
| made in Paint, Photoshop; by cameras and scanners | made in CorelDRAW, Illustrator, Inkscape |
| formats: .jpg, .png, .gif, .bmp, .tiff | formats: .svg, .ai, .cdr, .eps |

**Image file formats:** **JPEG (.jpg)** is used for photographs and makes files small; **PNG (.png)** keeps sharp edges and allows a see-through background; **GIF (.gif)** allows simple animations; **BMP (.bmp)** is uncompressed, so its files are large.

:::callout{type=local-example}
**Graphics at work.** A printing press in Freetown designs church programmes and wedding cards in **CorelDRAW** (vector) so that the logo prints sharply at any size, edits customers' photographs in **Photoshop** (bitmap), and a student designs a club poster on a phone in **Canva**.
:::

## Practice

:::reveal{title="1. Name two presentation programs and state two uses of presentation software."}
Programs (any two): **PowerPoint, Google Slides, Keynote, LibreOffice Impress, Prezi**. Uses (any two): **lessons**, **business presentations**, **training**, **school and church programmes**, **project defences**.
:::

:::reveal{title="2. Distinguish between a transition and an animation."}
A **transition** is the effect seen **as one slide changes to the next**. An **animation** is a movement effect given to **an object on a slide**.
:::

:::reveal{title="3. State three ways in which a presentation can be printed."}
Any three: as **full-page slides**; as **handouts** with several slides on each page for the audience; as **notes pages** with the speaker notes under each slide; as an **outline** of the text only.
:::

:::reveal{title="4. State three rules for designing good slides."}
Any three: keep text **short** (6 × 6 rule); use a **large** font (24 pt or more); use **strong contrast**; keep **one theme**; use transitions and animations **sparingly**; use **relevant pictures**; **check spelling**.
:::

:::reveal{title="5. State two differences between bitmap and vector graphics."}
Any two: bitmaps are made of **pixels**, vectors of **shapes** described by maths; bitmaps go **jagged** when enlarged, vectors stay **sharp**; bitmaps suit **photographs**, vectors suit **logos and diagrams**; vector files are usually **smaller**.
:::

## Key points

- **Presentation software** (PowerPoint, Google Slides, Impress) makes **slides** shown as a **slide show**.
- Terms: **placeholder, layout, theme, slide master, transition** (between slides), **animation** (objects), **speaker notes**, **handouts**.
- Views: **Normal, Slide Sorter, Notes Page, Reading, Slide Show**; **F5** starts the show, **Esc** ends it.
- Good slides: short text, large fonts, strong contrast, one theme, few effects.
- **Graphics software**: painting (Paint, Photoshop), drawing (CorelDRAW, Illustrator), DTP (Publisher), CAD (AutoCAD).
- **Bitmap** = pixels, jagged when enlarged, for photos; **vector** = maths shapes, always sharp, for logos.
