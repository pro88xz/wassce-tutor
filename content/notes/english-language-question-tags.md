*"You are coming, **aren't you**?"* *"She can't swim, **can she**?"* The short question at the end is a **question tag**. In conversation in Sierra Leone, one tag often does every job (*"…isn't it?"*, *"…not so?"*), but standard English builds each tag from the sentence it follows, and WASSCE tests that in the objective paper almost every year. The rules are few and precise. This lesson teaches them all, including the exceptions that make up most of the hard questions.

## Learning objectives

By the end of this lesson you should be able to:

- form a question tag from the auxiliary and subject of the sentence
- choose a negative or positive tag correctly
- handle sentences with no auxiliary (using *do, does, did*)
- apply the special cases: *I am*, *let's*, imperatives, *there*, negative words and indefinite pronouns

## How a tag is built

:::callout{type=definition}
A **question tag** is a short question added to the end of a statement. It is made of:

1. the **auxiliary verb** (or *be*) from the statement, and
2. a **pronoun** for the subject of the statement.

The tag has the **opposite polarity**: a **positive** statement takes a **negative** tag; a **negative** statement takes a **positive** tag.
:::

| Statement | Auxiliary + subject | Tag |
|---|---|---|
| *You **are** ready,* | are + you → negative | ***aren't you?*** |
| *She **can** drive,* | can + she → negative | ***can't she?*** |
| *They **have** left,* | have + they → negative | ***haven't they?*** |
| *He **isn't** here,* | is + he → positive | ***is he?*** |
| *We **won't** be late,* | will + we → positive | ***will we?*** |

:::callout{type=common-mistake}
**Using the noun instead of a pronoun.** *"Musa is your brother, isn't **Musa**?"* is wrong. The tag always uses a **pronoun**: *"…isn't **he**?"*
:::

## When there is no auxiliary: do, does, did

If the statement has only a main verb in the present simple or past simple, the tag uses **do / does / did**:

| Statement | Tag |
|---|---|
| *You **live** in Kenema,* | ***don't you?*** |
| *She **sells** fish,* | ***doesn't she?*** |
| *They **went** home,* | ***didn't they?*** |
| *He **didn't** pay,* | ***did he?*** |

:::callout{type=tip}
To find the right form of *do*, ask how you would make the statement a question: *Does she sell fish?* → the tag is ***doesn't she?***. *Did they go home?* → ***didn't they?***
:::

## The special cases

These are the questions that separate strong candidates from the rest.

| Case | Rule | Example |
|---|---|---|
| **I am** | the tag is ***aren't I?*** | *I am late, **aren't I**?* |
| **Let's** (suggestion) | ***shall we?*** | *Let's go to the beach, **shall we**?* |
| **Imperative** (command) | ***will you? / won't you? / can you?*** | *Close the door, **will you**?* / *Sit down, **won't you**?* |
| **Negative imperative** | ***will you?*** | *Don't be late, **will you**?* |
| **There is / there are** | keep ***there*** | *There is a problem, **isn't there**?* |
| **Negative words** (*never, hardly, scarcely, seldom, rarely, no, nothing, nobody*) | the statement counts as **negative**, so the tag is **positive** | *She **never** complains, **does she**?* / *He **hardly** eats, **does he**?* |
| **Everyone, everybody, someone, nobody** | tag with ***they*** | *Everyone has arrived, **haven't they**?* / *Nobody called, **did they**?* |
| **Nothing, everything** | tag with ***it*** | *Nothing happened, **did it**?* |
| **This / that** | tag with ***it*** | *That is your bag, **isn't it**?* |
| **These / those** | tag with ***they*** | *These are yours, **aren't they**?* |
| **Used to** | ***didn't*** | *You used to live here, **didn't you**?* |
| **Had better** | ***hadn't*** | *We had better leave, **hadn't we**?* |
| **'d** = had or would | decide which | *You'**d** finished, **hadn't you**?* / *You'**d** help, **wouldn't you**?* |

:::callout{type=worked-example}
*"Nobody saw the accident, ____?"*

A. didn't he B. did they C. didn't they D. did he

1. *Nobody* is a **negative** word, so the tag is **positive**: *did*.
2. *Nobody* takes the pronoun **they**.
3. **Answer: B. did they?**
:::

:::callout{type=worked-example}
*"He has to leave now, ____?"*

A. hasn't he B. doesn't he C. has he D. isn't he

*Has to* here means *must* (a main verb, not the auxiliary *have*), so the tag uses *do*: **B. doesn't he?**
:::

## Intonation reminder

How a tag is **said** changes its meaning (see the Oral English lesson on intonation):

- **Falling** tune: the speaker is sure and expects agreement.
- **Rising** tune: the speaker is genuinely asking.

:::callout{type=local-example}
| Common in speech | Standard English |
|---|---|
| *You are coming, isn't it?* | *You are coming, **aren't you**?* |
| *She went to Bo, not so?* | *She went to Bo, **didn't she**?* |
| *They can't come, isn't it?* | *They can't come, **can they**?* |
:::

## Key points

- A tag = **auxiliary + pronoun**, with the **opposite polarity** to the statement.
- No auxiliary? Use **do / does / did**.
- **I am → aren't I; Let's → shall we; imperatives → will you.**
- **Never, hardly, seldom, rarely, no, nothing, nobody** make the statement negative, so the tag is **positive**.
- **Everyone/nobody → they; nothing/this/that → it; there is → isn't there.**

## WASSCE examination focus

:::callout{type=waec-tests}
Question tags appear regularly in the objective paper's structure questions. The straightforward ones test auxiliary and pronoun matching; the harder ones test the special cases (*I am, let's, nobody, hardly, there, used to, has to*). Learn the table of special cases thoroughly.
:::
