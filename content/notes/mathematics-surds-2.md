$\sqrt{50}$ and $5\sqrt{2}$ are the same number, but only the second is in simplest form, and only in simplest form can surds be added, compared and used in exact answers. This lesson covers simplifying surds, adding and multiplying them, and **rationalising the denominator**, which WASSCE tests in almost every paper.

## Learning objectives

By the end of this lesson you should be able to:

- simplify surds by extracting perfect-square factors
- add and subtract like surds
- multiply surds and expand brackets containing surds
- rationalise denominators of the forms $\dfrac{a}{\sqrt{b}}$ and $\dfrac{a}{b + \sqrt{c}}$
- evaluate surd expressions given approximate values

## Simplifying surds

Use $\sqrt{ab} = \sqrt{a}\sqrt{b}$ with $a$ the **largest perfect square** factor.

:::callout{type=worked-example}
**Simplify (a) $\sqrt{50}$ (b) $\sqrt{75}$ (c) $\sqrt{72}$ (d) $\sqrt{\tfrac{18}{49}}$.**

**(a)** $\sqrt{25 \times 2} = 5\sqrt{2}$ **(b)** $\sqrt{25 \times 3} = 5\sqrt{3}$

**(c)** $\sqrt{36 \times 2} = 6\sqrt{2}$ (not $2\sqrt{18}$: always use the largest square factor)

**(d)** $\dfrac{\sqrt{9 \times 2}}{\sqrt{49}} = \dfrac{3\sqrt{2}}{7}$
:::

## Adding and subtracting surds

Only **like surds** (the same number under the root) can be combined, just as $3x + 5x = 8x$. Simplify first to reveal like surds.

:::callout{type=worked-example}
**Simplify (a) $3\sqrt{2} + 5\sqrt{2}$ (b) $\sqrt{12} + \sqrt{27}$ (c) $\sqrt{50} - \sqrt{18} + \sqrt{8}$.**

**(a)** $8\sqrt{2}$

**(b)** $2\sqrt{3} + 3\sqrt{3} = 5\sqrt{3}$

**(c)** $5\sqrt{2} - 3\sqrt{2} + 2\sqrt{2} = 4\sqrt{2}$
:::

:::callout{type=common-mistake}
$\sqrt{9} + \sqrt{16} = 3 + 4 = 7$, but $\sqrt{9 + 16} = \sqrt{25} = 5$. In general $\sqrt{a} + \sqrt{b} \ne \sqrt{a + b}$.
:::

## Multiplying surds

$\sqrt{a} \times \sqrt{b} = \sqrt{ab}$ and $\sqrt{a} \times \sqrt{a} = a$. Expand brackets as in algebra.

:::callout{type=worked-example}
**Simplify (a) $\sqrt{6} \times \sqrt{15}$ (b) $(\sqrt{5} + 2)^2$ (c) $(2 + \sqrt{3})(2 - \sqrt{3})$.**

**(a)** $\sqrt{90} = \sqrt{9 \times 10} = 3\sqrt{10}$

**(b)** $5 + 4\sqrt{5} + 4 = 9 + 4\sqrt{5}$

**(c)** $4 - 2\sqrt{3} + 2\sqrt{3} - 3 = 1$
:::

Part (c) shows something important: $(a + \sqrt{b})(a - \sqrt{b}) = a^2 - b$, which has **no surd**. The expressions $a + \sqrt{b}$ and $a - \sqrt{b}$ are called **conjugates**.

## Rationalising the denominator

To rationalise means to rewrite a fraction so that the denominator has no surd.

**Denominator $\sqrt{b}$:** multiply top and bottom by $\sqrt{b}$.

:::callout{type=worked-example}
**Rationalise (a) $\dfrac{6}{\sqrt{3}}$ (b) $\dfrac{5}{2\sqrt{5}}$.**

**(a)** $\dfrac{6\sqrt{3}}{3} = 2\sqrt{3}$ **(b)** $\dfrac{5\sqrt{5}}{2 \times 5} = \dfrac{\sqrt{5}}{2}$
:::

**Denominator $a + \sqrt{b}$ or $a - \sqrt{b}$:** multiply top and bottom by the **conjugate**.

:::callout{type=worked-example}
**Rationalise (a) $\dfrac{1}{\sqrt{5} - 2}$ (b) $\dfrac{3}{2 + \sqrt{2}}$ (c) $\dfrac{\sqrt{3} + \sqrt{2}}{\sqrt{3} - \sqrt{2}}$.**

**(a)** $\dfrac{\sqrt{5} + 2}{(\sqrt{5} - 2)(\sqrt{5} + 2)} = \dfrac{\sqrt{5} + 2}{5 - 4} = \sqrt{5} + 2$

**(b)** $\dfrac{3(2 - \sqrt{2})}{4 - 2} = \dfrac{6 - 3\sqrt{2}}{2}$

**(c)** $\dfrac{(\sqrt{3} + \sqrt{2})^2}{3 - 2} = 3 + 2\sqrt{6} + 2 = 5 + 2\sqrt{6}$
:::

## Using approximate values

:::callout{type=worked-example}
**Given $\sqrt{2} = 1.414$, evaluate $\dfrac{1}{\sqrt{2}}$ to 3 decimal places.**

Rationalise first: $\dfrac{1}{\sqrt{2}} = \dfrac{\sqrt{2}}{2} = \dfrac{1.414}{2} = 0.707$.

Rationalising turns a hard division by $1.414$ into an easy division by 2.
:::

## Key points

- **Simplify:** take out the largest perfect-square factor.
- **Add/subtract:** only like surds; simplify first.
- **Multiply:** $\sqrt{a}\sqrt{b} = \sqrt{ab}$; $(a + \sqrt{b})(a - \sqrt{b}) = a^2 - b$.
- **Rationalise:** multiply by $\sqrt{b}$, or by the **conjugate** for $a \pm \sqrt{b}$.
- $\sqrt{a} + \sqrt{b} \ne \sqrt{a + b}$.

## WASSCE examination focus

:::callout{type=waec-tests}
Expect to **simplify expressions such as $\sqrt{48} - \sqrt{27} + \sqrt{12}$**, to **expand brackets with surds**, and to **rationalise denominators**, often giving the answer in the form $a + b\sqrt{c}$. Questions may ask you to find the values of $a$ and $b$ after rationalising.
:::

## Practice

Try each question first, then open the answer to check your working.

**1.** Simplify $\sqrt{48} - \sqrt{27} + \sqrt{12}$.

:::reveal{title="Show the answer"}
$4\sqrt{3} - 3\sqrt{3} + 2\sqrt{3} = 3\sqrt{3}$.
:::

**2.** Expand $(3 - \sqrt{2})^2$.

:::reveal{title="Show the answer"}
$9 - 6\sqrt{2} + 2 = 11 - 6\sqrt{2}$.
:::

**3.** Rationalise $\dfrac{10}{\sqrt{5}}$.

:::reveal{title="Show the answer"}
$\dfrac{10\sqrt{5}}{5} = 2\sqrt{5}$.
:::

**4.** Rationalise $\dfrac{4}{3 - \sqrt{5}}$.

:::reveal{title="Show the answer"}
$\dfrac{4(3 + \sqrt{5})}{9 - 5} = 3 + \sqrt{5}$.
:::

**5.** Express $\dfrac{1 + \sqrt{3}}{1 - \sqrt{3}}$ in the form $a + b\sqrt{3}$.

:::reveal{title="Show the answer"}
$\dfrac{(1 + \sqrt{3})^2}{1 - 3} = \dfrac{4 + 2\sqrt{3}}{-2} = -2 - \sqrt{3}$, so $a = -2$, $b = -1$.
:::
