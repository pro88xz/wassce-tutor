:::callout{type=definition}
**Software** is the set of programs, data and instructions that tell a computer what to do. Unlike hardware, software cannot be touched. There are two main types of software: **system software** and **application software**.
:::

A computer with no software is just metal and plastic. Software turns it into a tool for typing a letter, calculating results, browsing the Internet or playing music. This lesson explains the **types of software**, the **difference between system software and application software**, the parts of system software (operating systems, utility programs, language translators and device drivers), the kinds of application software, and how software is obtained and licensed.

## Learning objectives

By the end of this lesson you should be able to:

- define software and distinguish it from hardware
- state the difference between system software and application software
- name the types of system software and give examples of utility programs
- classify application software as general-purpose, special-purpose or bespoke
- explain off-the-shelf and custom-written software, with advantages of each
- explain software licences: proprietary, freeware, shareware and open-source

## Hardware and software

| Hardware | Software |
|---|---|
| the **physical** parts of a computer | the **programs** that run on it |
| can be touched | cannot be touched |
| keyboard, monitor, CPU, printer | Windows, Microsoft Word, a game |
| wears out with use | does not wear out, but may have bugs or go out of date |

Hardware and software need each other: hardware does nothing without software, and software cannot run without hardware.

:::callout{type=definition}
**System software:** programs that control and manage the computer's hardware and provide a platform on which application software runs, such as the operating system and utility programs.

**Application software:** programs designed to help the user carry out particular tasks, such as writing a letter, calculating a budget or editing a photograph.
:::

| System software | Application software |
|---|---|
| runs and **manages the computer** | does a **task for the user** |
| works in the background | the user works with it directly |
| needed for the computer to work at all | installed when the user needs it |
| installed first (usually with the computer) | runs **on top of** system software |
| examples: Windows, Android, antivirus, a compiler | examples: Microsoft Word, Excel, a web browser, a game |

## System software

### 1. The operating system

The **operating system (OS)** is the most important system software: it starts the computer, manages its resources and lets the user and other programs use the hardware. Examples are **Windows**, **macOS** and **Linux** on computers and **Android** and **iOS** on phones. (Operating systems have their own lesson.)

### 2. Utility programs

:::callout{type=definition}
**Utility program (utility software):** a system program that helps to maintain, protect or improve the performance of a computer.
:::

| Utility | What it does |
|---|---|
| **Antivirus** | finds and removes viruses and other malware |
| **Backup** | makes copies of files so they can be restored if lost |
| **Disk cleanup** | deletes temporary and unwanted files to free space |
| **Disk defragmenter** | rearranges the pieces of files on a hard disk so they load faster |
| **File compression** | makes files smaller (zips them) for storing or sending |
| **Disk formatter** | prepares a disk or flash drive for use |
| **Firewall** | blocks unwanted network traffic |

### 3. Language translators

Programmers write in programming languages, but the processor understands only machine code. The three kinds of translator, the **assembler**, the **compiler** and the **interpreter**, are compared in the lesson on programming languages and translators.

### 4. Device drivers

:::callout{type=definition}
**Device driver:** a small program that lets the operating system communicate with a particular hardware device, such as a printer, scanner or graphics card.
:::

When you connect a new printer, the computer needs its driver before it can print.

:::callout{type=definition}
**Firmware:** software held permanently in ROM or flash memory inside a device to control it, such as the start-up program of a computer or the program in a washing machine or a TV remote.
:::

## Application software

:::callout{type=definition}
**General-purpose software (application package):** ready-made software that can be used for many different tasks of the same kind, such as a word processor or a spreadsheet.

**Special-purpose software:** software written to do one particular kind of job, such as payroll, school result processing or hotel booking.

**Bespoke (custom-written or tailor-made) software:** software written specially for one person or organisation to meet its exact needs.
:::

| Type of package | Use | Examples |
|---|---|---|
| **Word processor** | typing and formatting documents | Microsoft Word, Google Docs, LibreOffice Writer |
| **Spreadsheet** | calculations, tables of numbers, charts | Microsoft Excel, Google Sheets, LibreOffice Calc |
| **Database management system** | storing and searching records | Microsoft Access, MySQL |
| **Presentation** | slide shows | Microsoft PowerPoint, Google Slides |
| **Desktop publishing (DTP)** | newsletters, posters, magazines | Microsoft Publisher, Adobe InDesign |
| **Graphics** | drawing and editing pictures | CorelDRAW, Adobe Photoshop, Paint |
| **Web browser** | viewing web pages | Google Chrome, Mozilla Firefox, Microsoft Edge |
| **Accounting** | keeping business accounts | Sage, QuickBooks |

:::callout{type=definition}
**Office suite (integrated package):** a set of application programs sold or installed together, such as Microsoft Office or LibreOffice, whose word processor, spreadsheet, database and presentation programs look alike and exchange data easily.
:::

### Off-the-shelf and bespoke software

| Off-the-shelf (ready-made) | Bespoke (custom-written) |
|---|---|
| **cheaper**, because many people share the cost | **expensive**, because it is written for one buyer |
| available **at once** | takes **time** to write and test |
| well tested by many users; help and training easy to find | fits the organisation's **exact needs** |
| may have features you do not need, or lack some you do | can be changed when needs change |

## Software licences

:::callout{type=definition}
**Proprietary (commercial) software:** software owned by a company that must be paid for under a licence, which forbids copying or changing it, such as Microsoft Office.

**Freeware:** software that may be used without paying, but whose source code is kept secret, such as many free mobile apps.

**Shareware:** software that may be tried free for a limited time or with limited features, after which it must be paid for.

**Open-source software:** software whose source code is published so anyone may read, change and share it, usually at no cost, such as Linux, LibreOffice and Mozilla Firefox.
:::

:::callout{type=local-example}
**Software in a Sierra Leone school office.** The computers run **Windows** (system software); the bursar keeps fees in **Excel** (general-purpose); the school's results may be processed with a **special-purpose** results program; an **antivirus** protects files brought in on flash drives; and the printer works because its **driver** is installed.
:::

:::callout{type=common-mistake}
**Calling an antivirus program "application software".** Antivirus programs look after the computer itself, so they are **utility programs**, a kind of **system software**.
:::

## Practice

:::reveal{title="1. State two differences between system software and application software."}
Any two: system software **manages the computer**, application software does **tasks for the user**; system software is needed for the computer to work, application software is optional; application software runs **on top of** system software; examples: Windows (system) and Microsoft Word (application).
:::

:::reveal{title="2. Name four types of system software."}
The **operating system**, **utility programs**, **language translators** and **device drivers**.
:::

:::reveal{title="3. Give three examples of utility programs and the job of each."}
Any three: **antivirus** (removes malware), **backup** (copies files), **disk cleanup** (frees space), **defragmenter** (speeds up the hard disk), **file compression** (makes files smaller), **disk formatter** (prepares a disk).
:::

:::reveal{title="4. State two advantages of off-the-shelf software over bespoke software."}
Any two: it is **cheaper**; it is available **immediately**; it has been **tested** by many users; **help and training** are easy to find.
:::

:::reveal{title="5. What is open-source software? Give one example."}
Software whose **source code is freely available** to be read, changed and shared, usually at no cost. Examples: **Linux**, **LibreOffice**, **Firefox**.
:::

## Key points

- **Software** is the programs that tell the hardware what to do.
- **System software** runs the computer: **operating system, utility programs, language translators, device drivers**.
- **Application software** does users' tasks: **general-purpose packages** (word processor, spreadsheet, database, presentation, DTP, graphics), **special-purpose** and **bespoke** software.
- **Off-the-shelf** software is cheap and ready now; **bespoke** software fits exact needs but costs more and takes time.
- Licences: **proprietary, freeware, shareware, open-source**.
