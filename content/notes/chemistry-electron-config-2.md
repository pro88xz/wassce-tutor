Three rules decide exactly where every electron goes: the Aufbau principle, Pauli's exclusion principle and Hund's rule. With them you can write the configuration of any element up to zinc, show it in orbital boxes, and read off the element's place in the periodic table. This lesson puts the rules to work.

## Learning objectives

By the end of this lesson you should be able to:

- state the Aufbau principle, Pauli's exclusion principle and Hund's rule
- draw orbital box diagrams for elements 1 to 30
- write configurations of elements 1 to 30, including chromium and copper
- write configurations of ions, including transition metal ions
- find an element's period, group and block from its configuration

## The three rules

:::callout{type=definition}
1. **Aufbau principle:** electrons fill the **lowest-energy** orbitals first.
2. **Pauli's exclusion principle:** an orbital holds **at most two electrons**, and they must have **opposite spins** (↑↓).
3. **Hund's rule:** electrons fill orbitals of the **same sub-shell singly first**, with **parallel spins**, before any pairing occurs.
:::

Hund's rule works like passengers on a bus: people take empty double seats first, and only start sharing when every seat has someone in it. Electrons repel each other, so they spread out.

## Orbital box diagrams

![Orbital boxes for nitrogen (2p electrons unpaired in three boxes), oxygen (one 2p box paired) and iron (3d6 4s2)](https://wasscetutor.com/img/chemistry/orbital-boxes.svg)

*Figure 1. Box diagrams follow Pauli's principle and Hund's rule. WASSCE Tutor diagram.*

:::callout{type=worked-example}
**Nitrogen (Z = 7): $1s^2\,2s^2\,2p^3$.**

The three 2p electrons go into the **three separate** 2p boxes with parallel spins (↑ ↑ ↑), not ↑↓ ↑ and an empty box. Nitrogen therefore has **three unpaired electrons** and forms **three** covalent bonds, as in NH₃.

**Oxygen (Z = 8): $1s^2\,2s^2\,2p^4$.** The fourth 2p electron pairs up: ↑↓ ↑ ↑. Oxygen has **two unpaired electrons** and forms **two** bonds, as in H₂O.
:::

## Configurations of elements 1 to 30

The **noble-gas core** shortens long configurations: [Ne] stands for $1s^2\,2s^2\,2p^6$ and [Ar] for $1s^2\,2s^2\,2p^6\,3s^2\,3p^6$.

| Element | Z | Configuration |
|---|---|---|
| Na | 11 | [Ne] 3s¹ |
| Mg | 12 | [Ne] 3s² |
| P | 15 | [Ne] 3s² 3p³ |
| Ar | 18 | [Ne] 3s² 3p⁶ |
| K | 19 | [Ar] 4s¹ |
| Ca | 20 | [Ar] 4s² |
| Sc | 21 | [Ar] 3d¹ 4s² |
| V | 23 | [Ar] 3d³ 4s² |
| **Cr** | 24 | **[Ar] 3d⁵ 4s¹** (not 3d⁴ 4s²) |
| Mn | 25 | [Ar] 3d⁵ 4s² |
| Fe | 26 | [Ar] 3d⁶ 4s² |
| Ni | 28 | [Ar] 3d⁸ 4s² |
| **Cu** | 29 | **[Ar] 3d¹⁰ 4s¹** (not 3d⁹ 4s²) |
| Zn | 30 | [Ar] 3d¹⁰ 4s² |

**Chromium and copper are exceptions.** A **half-filled** (d⁵) or **completely filled** (d¹⁰) d sub-shell is especially stable, so one 4s electron moves into 3d.

## Configurations of ions

- **Negative ions:** add electrons to the next available orbital. Cl⁻ is $1s^2\,2s^2\,2p^6\,3s^2\,3p^6$ (like argon).
- **Positive ions:** remove electrons from the **outermost shell first**. For transition metals, the **4s electrons are removed before 3d**.

:::callout{type=worked-example}
**Iron ions.** Fe is [Ar] 3d⁶ 4s².

- Fe²⁺: remove the two 4s electrons → **[Ar] 3d⁶**
- Fe³⁺: remove one more, from 3d → **[Ar] 3d⁵**

Fe³⁺ has a half-filled d sub-shell, which is one reason iron(III) compounds are stable in air.
:::

## Configuration and the periodic table

| From the configuration | You can read |
|---|---|
| Highest shell number (n) | The **period** |
| Number of outer (valence) electrons | The **group** (for s- and p-block elements) |
| Sub-shell being filled last | The **block**: s, p, d or f |

:::callout{type=worked-example}
**An element is $1s^2\,2s^2\,2p^6\,3s^2\,3p^4$. Identify it.**

- Highest shell n = 3, so **period 3**.
- Outer electrons 3s² 3p⁴ = **6**, so **group 6 (VI)**.
- Last electron in a **p** sub-shell, so **p-block**.
- Total electrons = 16, so it is **sulphur**.
:::

:::callout{type=common-mistake}
When forming transition-metal ions, remove the **4s electrons first**, even though 4s filled before 3d. Writing Fe²⁺ as [Ar] 3d⁴ 4s² is wrong.
:::

## Key points

- **Aufbau**: lowest energy first. **Pauli**: two electrons per orbital, opposite spins. **Hund**: singly before pairing.
- Use **noble-gas cores** ([Ne], [Ar]) to shorten configurations.
- **Cr = [Ar] 3d⁵ 4s¹** and **Cu = [Ar] 3d¹⁰ 4s¹** because half-filled and filled d sub-shells are extra stable.
- In transition-metal **ions, 4s electrons are lost before 3d**.
- From a configuration read the **period** (n), **group** (outer electrons) and **block** (last sub-shell).

## Quick check

1. State Hund's rule.
2. Write the configuration of chromium.
3. Write the configuration of Cu²⁺.
4. An element is [Ne] 3s² 3p¹. Give its period, group and block.

**Answers:**

1. Electrons occupy orbitals of the same sub-shell singly, with parallel spins, before pairing up.
2. [Ar] 3d⁵ 4s¹, i.e. $1s^2\,2s^2\,2p^6\,3s^2\,3p^6\,3d^5\,4s^1$.
3. Cu is [Ar] 3d¹⁰ 4s¹; remove the 4s electron, then one 3d electron: [Ar] 3d⁹.
4. Period 3, group 3 (III), p-block: aluminium.
