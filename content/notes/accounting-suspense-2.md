A **suspense account question** usually asks you to (1) **journalise the corrections** of a list of errors, (2) **write up the suspense account** until it closes with a **nil balance**, and (3) prepare a **statement of corrected net profit**. The key is to decide for each error whether it touches the suspense account and in which direction it changes profit. This lesson works through a complete WASSCE-style suspense account question with every step shown.

## Learning objectives

By the end of this lesson you should be able to:

- journalise corrections involving the suspense account
- write up and close the suspense account
- prepare a statement of corrected net profit
- explain the effect of each error on gross and net profit

## Worked example

:::callout{type=worked-example}
**The trial balance of Mansaray Enterprises at 31 December 2026 showed debits of NLe 89,600 and credits of NLe 90,300. The difference was placed in a suspense account, and a draft net profit of NLe 25,000 was calculated. Later the following errors were found:**

1. Wages of 900 paid in cash were entered in the cash book but not posted to the wages account.
2. The sales account was undercast by 200.
3. A cheque of 1,100 received from Kamara was credited to Kamah's account.

**Required:** (a) journal entries; (b) the suspense account; (c) a statement of corrected net profit.
:::

**(a) Journal entries**

| No. | Particulars | Dr NLe | Cr NLe |
|---|---|---|---|
| 1 | Wages | 900 | |
| | Suspense | | 900 |
| | *Wages not posted to the wages account* | | |
| 2 | Suspense | 200 | |
| | Sales | | 200 |
| | *Sales account undercast* | | |
| 3 | Kamah | 1,100 | |
| | Kamara | | 1,100 |
| | *Cheque from Kamara credited to Kamah* | | |

Error 3 is an **error of commission**: it did not affect the trial balance, so it does **not** go through suspense.

**(b) Suspense account**

| Dr | NLe | Cr | NLe |
|---|---|---|---|
| Difference in TB | 700 | Wages | 900 |
| Sales | 200 | | |
| **Total** | **900** | **Total** | **900** |

The account closes with **no balance**: all the errors causing the difference have been found.

**(c) Statement of corrected net profit**

| | NLe |
|---|---|
| Draft net profit | 25,000 |
| Add: sales undercast (2) | 200 |
| | 25,200 |
| Less: wages not charged (1) | (900) |
| **Corrected net profit** | **24,300** |

Error 3 affects only personal accounts, so it has **no effect** on profit.

## Effect of errors on profit: a guide

| Correction increases | Effect on profit |
|---|---|
| income (sales, discount received, rent received) | profit **up** |
| an expense (wages, rent, purchases, carriage) | profit **down** |
| reduces an expense | profit **up** |
| reduces income | profit **down** |
| only assets, liabilities, capital or personal accounts | **no effect** |

Errors in **sales, purchases, returns, carriage inwards or closing inventory** change **gross profit** as well as net profit; errors in other expenses and income change **net profit only**.

:::callout{type=worked-example}
**Effect of two more errors on net profit.**

- **Discount received of 400 was posted to the debit of the discount allowed account.** Correction: debit suspense 800, credit discount allowed 400 and discount received 400. Expense down 400 and income up 400, so profit **rises by 800**.
- **A new office desk for 2,500 was debited to the repairs account.** Correction: debit furniture 2,500, credit repairs 2,500 (error of principle, no suspense). Expense down 2,500, so profit **rises by 2,500**.
:::

:::callout{type=common-mistake}
Check that the suspense account **closes with a nil balance**. If it does not, an error has been missed or corrected in the wrong direction. Re-check each error: is the correction on the side that **removes** the difference?
:::

## Key points

- Journalise each error; only errors that affected the trial balance go through **suspense**.
- The completed **suspense account** must close with a **nil balance**.
- **Corrected net profit** = draft profit **+** items that raise profit **−** items that lower it.
- Errors in personal, asset, liability and capital accounts **do not change profit**.

## WASSCE examination focus

:::callout{type=waec-tests}
This is a classic Paper 2 question: **journal entries, the suspense account and a statement of corrected net profit**. Show the opening difference as the first entry in the suspense account, total both sides, and set out the profit statement with additions and deductions clearly labelled.
:::

## Quick check

1. A trial balance has credits NLe 1,500 greater than debits. What is the opening suspense entry?
2. Rent received of NLe 600 was not posted to the rent received account. Give the correction.
3. What is the effect of the correction in question 2 on net profit?
4. Why does an error of commission not appear in the suspense account?
5. Draft profit is NLe 18,000. Sales were overcast by NLe 1,000. Find the corrected profit.

**Answers:**

1. Debit suspense NLe 1,500.
2. Debit suspense 600; credit rent received 600.
3. Net profit increases by NLe 600.
4. Because it did not affect the agreement of the trial balance.
5. $18\,000 - 1\,000 = 17\,000$: NLe 17,000.
