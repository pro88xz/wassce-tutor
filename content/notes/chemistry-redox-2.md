How can you tell whether chlorine is oxidised or reduced when it reacts with sodium hydroxide, when no oxygen, hydrogen or obvious electron transfer is involved? You use **oxidation numbers**. They also give compounds their proper IUPAC names, such as potassium manganate(VII) and iron(III) chloride. This lesson teaches the rules and how to use them.

## Learning objectives

By the end of this lesson you should be able to:

- state the rules for assigning oxidation numbers
- calculate the oxidation number of an element in a compound or ion
- use changes in oxidation number to identify oxidation and reduction
- balance redox equations using half-equations
- name compounds using IUPAC oxidation-number nomenclature

## Rules for oxidation numbers

:::callout{type=definition}
The **oxidation number** (oxidation state) of an atom is the **charge it would have** if all its bonds were ionic.
:::

1. Any **uncombined element** has oxidation number **0**: Na, O₂, Cl₂, S₈.
2. A **simple ion** has an oxidation number equal to its **charge**: Na⁺ = +1, Cl⁻ = −1, Fe³⁺ = +3.
3. In a **neutral compound**, the oxidation numbers add up to **0**.
4. In a **polyatomic ion**, the oxidation numbers add up to the **charge of the ion**.
5. Usual values in compounds:
   - group 1 metals: **+1**; group 2 metals: **+2**; aluminium: **+3**
   - hydrogen: **+1** (but −1 in metal hydrides such as NaH)
   - oxygen: **−2** (but −1 in peroxides such as H₂O₂, and +2 in OF₂)
   - fluorine: always **−1**

## Calculating oxidation numbers

:::callout{type=worked-example}
**Find the oxidation number of the underlined element.**

1. **Mn in KMnO₄:** $(+1) + \text{Mn} + 4(-2) = 0 \Rightarrow \text{Mn} = +7$
2. **Cr in K₂Cr₂O₇:** $2(+1) + 2\text{Cr} + 7(-2) = 0 \Rightarrow 2\text{Cr} = +12 \Rightarrow \text{Cr} = +6$
3. **S in SO₄²⁻:** $\text{S} + 4(-2) = -2 \Rightarrow \text{S} = +6$
4. **N in NH₄⁺:** $\text{N} + 4(+1) = +1 \Rightarrow \text{N} = -3$
5. **N in HNO₃:** $(+1) + \text{N} + 3(-2) = 0 \Rightarrow \text{N} = +5$
:::

Sulphur and nitrogen show many oxidation numbers:

| Sulphur | Nitrogen |
|---|---|
| H₂S: −2 | NH₃: −3 |
| S: 0 | N₂: 0 |
| SO₂, SO₃²⁻: +4 | NO: +2 |
| H₂SO₄, SO₄²⁻: +6 | NO₂: +4 |
| | HNO₃, NO₃⁻: +5 |

## Using oxidation numbers to spot redox

- An **increase** in oxidation number is **oxidation**.
- A **decrease** in oxidation number is **reduction**.

:::callout{type=worked-example}
**Chlorine with cold dilute sodium hydroxide.**

$$\text{Cl}_2 + 2\text{NaOH} \rightarrow \text{NaCl} + \text{NaClO} + \text{H}_2\text{O}$$

- Cl in Cl₂: **0**
- Cl in NaCl: **−1** (reduced)
- Cl in NaClO: **+1** (oxidised)

The **same element** is both oxidised and reduced. This is called **disproportionation**.
:::

:::callout{type=worked-example}
**Is this a redox reaction?** NaOH + HCl → NaCl + H₂O

Na stays +1, O −2, H +1 and Cl −1 throughout. **No oxidation number changes**, so neutralisation is **not** a redox reaction.
:::

## Balancing redox equations with half-equations

Steps (in acid solution):

1. Write the two half-equations.
2. Balance atoms other than O and H.
3. Balance **O** by adding **H₂O**; balance **H** by adding **H⁺**.
4. Balance **charge** by adding **electrons**.
5. Multiply so that both half-equations have the **same number of electrons**, then add and cancel.

:::callout{type=worked-example}
**Acidified potassium manganate(VII) oxidising iron(II) ions.**

Reduction:

$$\text{MnO}_4^- + 8\text{H}^+ + 5e^- \rightarrow \text{Mn}^{2+} + 4\text{H}_2\text{O}$$

Oxidation (× 5):

$$5\text{Fe}^{2+} \rightarrow 5\text{Fe}^{3+} + 5e^-$$

Overall:

$$\text{MnO}_4^- + 8\text{H}^+ + 5\text{Fe}^{2+} \rightarrow \text{Mn}^{2+} + 5\text{Fe}^{3+} + 4\text{H}_2\text{O}$$

Check the charge: left $-1 + 8 + 10 = +17$; right $+2 + 15 = +17$. ✓

Mn falls from +7 to +2 (reduced); Fe rises from +2 to +3 (oxidised). The purple MnO₄⁻ turns colourless, so this titration needs **no indicator**.
:::

## IUPAC names using oxidation numbers

Where an element can have more than one oxidation number, it is shown in **Roman numerals** in brackets.

| Formula | Old name | IUPAC name |
|---|---|---|
| FeCl₂ | Ferrous chloride | **Iron(II) chloride** |
| FeCl₃ | Ferric chloride | **Iron(III) chloride** |
| Cu₂O | Cuprous oxide | **Copper(I) oxide** |
| CuO | Cupric oxide | **Copper(II) oxide** |
| MnO₂ | Manganese dioxide | **Manganese(IV) oxide** |
| SO₂ | Sulphur dioxide | **Sulphur(IV) oxide** |
| KMnO₄ | Potassium permanganate | **Potassium manganate(VII)** |
| K₂Cr₂O₇ | Potassium dichromate | **Potassium dichromate(VI)** |
| Na₂SO₃ | Sodium sulphite | **Sodium sulphate(IV)** |
| Na₂SO₄ | Sodium sulphate | **Sodium sulphate(VI)** |
| NaNO₂ | Sodium nitrite | **Sodium nitrate(III)** |
| NaClO | Sodium hypochlorite | **Sodium chlorate(I)** |
| NaClO₃ | Sodium chlorate | **Sodium chlorate(V)** |

:::callout{type=local-example}
The "iron tablets" given to pregnant women at clinics in Sierra Leone contain **iron(II) sulphate**, FeSO₄. Iron(II) is used because the body absorbs it better than iron(III). Tablets are kept sealed because air slowly **oxidises** iron(II) to iron(III), and the green salt turns brownish.
:::

:::callout{type=common-mistake}
An oxidation number is written with the **sign before the number** (+3, −2), while an ion's charge is written with the **number before the sign** (Fe³⁺, O²⁻). Keep them distinct in your answers.
:::

## Key points

- Uncombined elements are **0**; in compounds the oxidation numbers add up to **0** (or to the ion's charge).
- Usual values: H **+1**, O **−2**, group 1 **+1**, group 2 **+2**, F **−1**.
- **Increase = oxidation; decrease = reduction**; no change means no redox (neutralisation).
- **Disproportionation:** the same element is oxidised and reduced (Cl₂ + NaOH).
- Balance redox equations with **half-equations**, matching electrons.
- **IUPAC names** show oxidation numbers in Roman numerals: iron(III) chloride, potassium manganate(VII).

## WASSCE examination focus

:::callout{type=waec-tests}
Expect to **calculate oxidation numbers** (Mn in KMnO₄, Cr in K₂Cr₂O₇, S and N in their compounds), to **decide whether a reaction is redox** and which element is oxidised, and to **give IUPAC names** of compounds. Balancing the MnO₄⁻/Fe²⁺ equation is a common higher-level question.
:::

## Quick check

1. Find the oxidation number of chlorine in NaClO₃.
2. Give the IUPAC name of Na₂SO₃.
3. In 2FeCl₂ + Cl₂ → 2FeCl₃, which element is oxidised? Give the change in oxidation number.
4. Is CaCO₃ → CaO + CO₂ a redox reaction? Explain.

**Answers:**

1. $(+1) + \text{Cl} + 3(-2) = 0$, so Cl = +5.
2. Sodium sulphate(IV).
3. Iron: +2 → +3.
4. No: no element changes its oxidation number (Ca +2, C +4, O −2 throughout).
