### 42. `maths-functions-07`

Which of the following relations is NOT a function?

- **C.** $\{(1, 4), (2, 5), (3, 6)\}$
- **D.** $\{(0, 0), (1, 1)\}$

A function gives each input exactly one output. In $\{(1, 2), (1, 3), (2, 4)\}$ the input 1 has two outputs, 2 and 3, so it is not a function (it is one-to-many).
