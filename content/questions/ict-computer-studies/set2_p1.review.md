- **A.** 5

An absolute reference has a dollar sign before both the column letter and the row number, so it always points to the same cell, such as a fixed exchange rate.

**Why the other options are wrong**

- a relative reference: A relative reference changes to keep the same position relative to the new cell.
- a mixed reference: A mixed reference fixes only the column or only the row; the other part changes.
- a range: A range is a block of cells, not a kind of reference.

Every formula in a spreadsheet must begin with
