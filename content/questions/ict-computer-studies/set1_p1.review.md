## Number Systems and Data Representation

### 20. `ict-ns-01`

Convert $37_{10}$ to binary.

- **A.** 100101  ✅
- **B.** 100111
- **C.** 101001
- **D.** 110101

Divide by 2 repeatedly: $37 \div 2 = 18$ r 1, $18 \div 2 = 9$ r 0, $9 \div 2 = 4$ r 1, $4 \div 2 = 2$ r 0, $2 \div 2 = 1$ r 0, $1 \div 2 = 0$ r 1. Reading the remainders upwards gives $100101_2$. Check: $32 + 4 + 1 = 37$.

**Why the other options are wrong**

- 101001: This reads the remainders downwards; it is 41, not 37.
- 100111: This is 39: the 2s place should be 0.
- 110101: This is 53: the 16s place should be 0.

---

### 21. `ict-ns-02`

Convert $110010_2$ to decimal.

- **A.** 19
- **B.** 48
- **C.** 50  ✅
- **D.** 52

Place values from the right are 1, 2, 4, 8, 16, 32. The 1s are in the 32, 16 and 2 places, so $32 + 16 + 2 = 50$.

**Why the other options are wrong**

- 19: This reads the bits in reverse order (010011).
- 52: This uses 4 instead of 2 for the second bit from the right.
- 48: This leaves out the 2s place.

Convert $3F_{16}$ to decimal.

F = 15. The places are 16s and units, so $3F_{16} = 3 \times 16 + 15 = 48 + 15 = 63$.

### 23. `ict-ns-04`

Add the binary numbers $1011_2 + 101_2$.

- **A.** 1110
- **B.** 1111
- **C.** 10000  ✅
- **D.** 10001

From the right: $1 + 1 = 10$, write 0 carry 1; $1 + 0 + 1 = 10$, write 0 carry 1; $0 + 1 + 1 = 10$, write 0 carry 1; $1 + 0 + 1 = 10$, write 0 carry 1; the last carry gives 1. Answer: $10000_2$. Check: $11 + 5 = 16$.

**Why the other options are wrong**

- 1111: This ignores the carries: 1 + 1 = 10 in binary, so write 0 and carry 1.
- 10001: This is 17; the sum of 11 and 5 is 16.
- 1110: This is 14; a carry has been lost.

## The CPU

_Syllabus: Control unit, ALU and registers; buses; the fetch-decode-execute cycle; processor speed_

### 27. `ict-cp-01`

Which part of the CPU performs calculations and comparisons?

- **A.** the control unit
- **B.** the program counter
- **C.** the arithmetic and logic unit (ALU)  ✅
- **D.** the data bus

The ALU carries out arithmetic (add, subtract, multiply, divide) and logic operations (comparisons and AND, OR, NOT) that let programs make decisions.

**Why the other options are wrong**

- the data bus: The data bus carries data between parts; it does no processing.

The program counter holds the address of the next instruction. During the fetch stage its value is copied to the MAR and it then goes up by one.

**Why the other options are wrong**

- the accumulator: The accumulator holds the result of the latest ALU calculation.
- the memory data register (MDR): The MDR holds the data or instruction being moved to or from memory.
- the current instruction register (CIR): The CIR holds the instruction being decoded and carried out now.

### 29. `ict-cp-03`

Which of the following is the correct order of the stages of the machine cycle?

- **A.** fetch, decode, execute  ✅
- **B.** decode, fetch, execute
- **C.** execute, fetch, decode
- **D.** fetch, execute, decode

For every instruction the CPU fetches it from memory, decodes it in the control unit, then executes it, often using the ALU. The cycle repeats billions of times a second.

**Why the other options are wrong**

- decode, fetch, execute: An instruction must be fetched before it can be decoded.
- execute, fetch, decode: An instruction cannot be carried out before it is fetched and decoded.
- fetch, execute, decode: The CPU must decode an instruction before it can carry it out.

The address bus carries addresses one way, from the CPU, to say which memory location or device is to be used. The data then travels on the data bus.

**Why the other options are wrong**

- the data bus: The data bus carries the data itself, in both directions.
- the control bus: The control bus carries signals such as read, write and clock timing.
- a USB cable: A USB cable connects external devices; it is not one of the CPU's internal buses.

- **A.** a thermal printer  ✅
- **B.** a plotter
- **C.** a daisy-wheel printer
- **D.** a 3D printer

A thermal printer uses heat on heat-sensitive paper. It is small, quiet and needs no ink, so it is used for receipts, ATM slips and tickets.

**Why the other options are wrong**

- a plotter: A plotter draws large plans and maps.
- a daisy-wheel printer: Daisy-wheel printers are old, slow letter-quality printers.
- a 3D printer: A 3D printer builds solid objects, not receipts.

### 46. `ict-ou-07`

The quality of a printer's output is measured in

- **A.** pages per minute (ppm)
- **B.** dots per inch (dpi)  ✅
- **C.** gigahertz (GHz)
- **D.** megabytes (MB)

Print quality (resolution) is measured in dots per inch: the more dots in each inch, the finer the print. Speed is measured in pages per minute or characters per second.

**Why the other options are wrong**

- pages per minute (ppm): Pages per minute measure printing speed, not quality.
- gigahertz (GHz): Gigahertz measure a processor's clock speed.
- megabytes (MB): Megabytes measure data and storage capacity.

## Memory and Storage Devices

_Syllabus: RAM and ROM; types of ROM; cache; magnetic, optical and solid-state storage; capacities_

### 47. `ict-ms-01`

Which memory loses its contents when the power is switched off?

- **A.** ROM
- **B.** a hard disk
- **C.** RAM  ✅
- **D.** a flash drive

RAM (random access memory) is volatile: it holds the programs and data in use and loses them when the power goes off. That is why work must be saved to storage.

**Why the other options are wrong**

- ROM: ROM is non-volatile; it keeps its contents without power.
- a hard disk: A hard disk is non-volatile secondary storage.
- a flash drive: Flash memory is non-volatile.

---

### 48. `ict-ms-02`

Which type of ROM can be erased with ultraviolet light and programmed again?

- **A.** PROM
- **B.** EEPROM
- **C.** DRAM
- **D.** EPROM  ✅

EPROM (erasable programmable ROM) is erased by shining ultraviolet light through a window on the chip, then rewritten. EEPROM is erased electrically; flash memory is a kind of EEPROM.

**Why the other options are wrong**

- PROM: A PROM can be written only once.
- EEPROM: EEPROM is erased electrically, not with ultraviolet light.
- DRAM: DRAM is a type of RAM, not ROM.

---

### 49. `ict-ms-03`

Which of the following is an optical storage medium?

- **A.** a DVD  ✅
- **B.** a hard disk
- **C.** a USB flash drive
- **D.** magnetic tape

Optical discs, CD, DVD and Blu-ray, are written and read with a laser. Hard disks and tape are magnetic; flash drives and SSDs are solid-state.

**Why the other options are wrong**

- a hard disk: A hard disk is magnetic storage.
- a USB flash drive: A flash drive is solid-state storage.
- magnetic tape: Magnetic tape is magnetic storage.

### 50. `ict-ms-04`

The usual storage capacity of a standard CD is about

- **A.** 4.7 GB
- **B.** 700 MB  ✅
- **C.** 25 GB
- **D.** 1.44 MB

A CD holds about 700 MB, a single-layer DVD 4.7 GB and a single-layer Blu-ray disc 25 GB.

**Why the other options are wrong**

- 4.7 GB: 4.7 GB is the capacity of a single-layer DVD.
- 25 GB: 25 GB is the capacity of a single-layer Blu-ray disc.
- 1.44 MB: 1.44 MB was the capacity of a floppy disk.

### 51. `ict-ms-05`

A small amount of very fast memory between the CPU and main memory, holding the most frequently used data, is called

- **A.** virtual memory
- **B.** ROM
- **C.** cache memory  ✅
- **D.** secondary storage

Cache memory, usually SRAM, sits on or near the CPU and keeps copies of the data and instructions used most often, so the CPU does not wait for slower RAM.

**Why the other options are wrong**

- virtual memory: Virtual memory is part of the disk used as extra RAM, which is slower, not faster.
- ROM: ROM holds fixed start-up instructions.
- secondary storage: Secondary storage is much slower than main memory.

### 52. `ict-ms-06`

Which of the following storage devices has no moving parts?

- **A.** a hard disk drive
- **B.** a DVD drive
- **C.** a magnetic tape drive
- **D.** a solid-state drive (SSD)  ✅

An SSD stores data in flash memory chips with no moving parts, so it is faster, silent and less easily damaged by knocks than a hard disk.

**Why the other options are wrong**

- a hard disk drive: A hard disk has spinning platters and moving read/write heads.
- a DVD drive: A DVD drive spins the disc under a laser.
- a magnetic tape drive: A tape drive winds the tape past the heads.

---

### 53. `ict-ms-07`

The start-up instructions (BIOS) of a computer are kept in

- **A.** ROM  ✅
- **B.** RAM
- **C.** cache memory
- **D.** the accumulator

ROM is non-volatile, so the start-up instructions are still there when the computer is switched on and can load the operating system from storage.

**Why the other options are wrong**

- RAM: RAM is volatile, so the instructions would be lost each time the computer is switched off.
- cache memory: Cache holds copies of frequently used data while the computer runs.
- the accumulator: The accumulator is a CPU register that holds a calculation result.
