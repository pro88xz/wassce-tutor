## Networks and Networking

_Syllabus: PAN, LAN, MAN and WAN; bus, star, ring and mesh topologies; network devices; transmission media; transmission modes_

### 1. `ict-nw-01`

The computers in one school's laboratory, linked to share a printer and files, form

- **A.** a local area network (LAN)  ✅
- **B.** a wide area network (WAN)
- **C.** a metropolitan area network (MAN)
- **D.** a personal area network (PAN)

A LAN covers a small area such as a room, a building or a school compound, and is usually owned by one organisation.

**Why the other options are wrong**

- a wide area network (WAN): A WAN covers countries or continents, not one building.
- a metropolitan area network (MAN): A MAN covers a whole town or city.
- a personal area network (PAN): A PAN links one person's devices within a few metres.

### 2. `ict-nw-02`

In which topology does a break in the single main cable stop the whole network?

- **A.** star
- **B.** bus  ✅
- **C.** mesh
- **D.** tree

In a bus topology every node shares one backbone cable with a terminator at each end, so a break in the backbone stops all communication.

**Why the other options are wrong**

- star: In a star, a broken cable cuts off only the computer on that cable.
- mesh: A mesh has many routes, so it keeps working if one link fails.
- tree: A tree joins several stars; a break affects only part of it.

### 3. `ict-nw-03`

Which device sends data only to the computer it is addressed to, rather than to every computer on the network?

- **A.** a hub
- **B.** a repeater
- **C.** a switch  ✅
- **D.** a modem

A switch reads the address on each piece of data and forwards it only to the right device, making the network faster and more private than one built on a hub.

**Why the other options are wrong**

- a hub: A hub sends every message out to all connected devices.
- a repeater: A repeater only boosts a weak signal.
- a modem: A modem converts signals for a telephone, cable or mobile line.

### 4. `ict-nw-04`

Which transmission medium carries data as pulses of light?

- **A.** twisted-pair cable
- **B.** coaxial cable
- **C.** microwave link
- **D.** fibre-optic cable  ✅

Fibre-optic cable sends pulses of light along thin glass fibres. It is very fast, works over long distances and is not affected by electrical interference.

**Why the other options are wrong**

- twisted-pair cable: Twisted pair carries electrical signals on copper wires.
- coaxial cable: Coaxial cable carries electrical signals on a copper core.
- microwave link: Microwaves are radio waves beamed through the air.

- **B.** a wide area network

## Computer Viruses and Cybersecurity

_Syllabus: Malware; how viruses spread; hacking and phishing; antivirus, firewall, encryption, 2FA; passwords_

### 29. `ict-cs-01`

Malware that spreads across networks by itself, without attaching to a file, is a

- **A.** worm  ✅
- **B.** virus
- **C.** Trojan horse
- **D.** cookie

Worms copy themselves from computer to computer across networks without any user action, often slowing networks down.

**Why the other options are wrong**

- virus: A virus needs to attach to a file that is opened or run.
- Trojan horse: A Trojan relies on the user installing it, and does not copy itself.
- cookie: A cookie is a small text file a website stores; it is not malware.

- **A.** a worm
